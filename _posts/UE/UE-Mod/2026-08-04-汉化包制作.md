## 补充

### FileList自动化

像上述那么写的话，所有的文件挂载路径都是UI/了，不适配其他项目，而一个一个写太麻烦，所以写了一个CreatePakFile.bat：

```bash
@echo off
chcp 65001 >nul
setlocal enabledelayedexpansion

:: bat所在目录
set "BAT_DIR=%~dp0"
:: 待扫描的源文件夹（bat目录下的ModTest）
set "SOURCE_DIR=%BAT_DIR%ModTest"
:: 输出列表文件，放在bat同级
set "OUT_TXT=%BAT_DIR%FileList.txt"

:: 清空旧文件
echo. > "%OUT_TXT%"

echo Scanning: %SOURCE_DIR%
echo Output: %OUT_TXT%

:: 遍历ModTest下所有文件
for /r "%SOURCE_DIR%" %%f in (*) do (
    set "FULL_LOCAL=%%f"
    :: 获取相对于 ModTest 的路径
    set "REL_PATH=!FULL_LOCAL:%SOURCE_DIR%\=!"
    :: 拼接pak内虚拟路径  ../../../ModTest/xxx
    set "PAK_VIRT=../../../ModTest/!REL_PATH:\=/!"
    :: 写入一行 "本地完整路径" "pak虚拟路径"
    echo "!FULL_LOCAL!" "!PAK_VIRT!" >> "%OUT_TXT%"
)

echo Done! FileList.txt generated.
pause
endlocal
```

#### 使用方法

首先你有一个类似路径：`D:\AAA\ProjectName`ProjectName是你的项目名此目录下有你从Fmodel里导出的资产，如：Content/UI/UI_HUD.uasset等，你需要将bat放在`D:\AAA\`目录下，接下来：

- 扫描子目录 `ProjectName` 下全部文件

- 输出 `FileList.txt` 到 bat 所在目录（D:\AAA\FileList.txt）

- 每行格式：`"完整本地路径" "../../../ProjectName/相对路径"`

同时之前说的打包bat文件也要对应更改：

```bash
F:\UE_5.4\Engine\Binaries\Win64\UnrealPak.exe "%~1.pak" -Create=D:\AAA\FileList.txt -compress
```

将AAA文件夹拖入到此bat文件上即可

# 存在locres文件不使用IoStore

前面讲述的都是不存在locres文件且不使用IoStore的情况。如果存在.locres文件的话会方便很多

分两种情况：1、作者没有制作语言切换功能，或没有制作切换到中文的功能。2、作者制作了语言切换功能



1、首先使用Fmodel打开，在Folders中找到Localization，右键他，选择Export Folder->Raw Data(.uasset)这样会将文件夹所有文件导出。同时你不能保证Localization不会分散在不同的pak中，因此你需要找全。

2、将导出的文件夹放入一个你认为正确的路径

3、这里体现出两种情况的不同，如果有制作中文语言，你会找到zh相关文件夹；如果没有比如我的测试工程就只有一个en文件夹。但是不论是否存在都只是替换文本文件而已，只不过你替换zh文件夹中的文件不会影响其他语言，你替换了en文件夹中的文件，那么当切换到英文语言时则会显示中文。

4、此处拿en文件夹举例，使用en文件夹中的`Game.locres`文件拖入到从[UE4 Locres Unpacker](https://github.com/lehieugch68/UE4-Locres-Unpacker/releases/tag/1.0.0.0)下载下来的`UE4-Locres-Unpacker.exe`中，这样会在en文件夹生成一个txt文件，你不要修改文件名，双击打开，翻译其中文字，保存后再将此txt拖入到`UE4-Locres-Unpacker.exe`，这时会在en文件夹中生成一个`Game-new.locres`文件，把原来的Game.locres文件和txt文件删除，将`Game-new.locres`文件重命名为`Game.locres`

5、删除你没有修改的locres文件，没有必要增加包体

6、打包
